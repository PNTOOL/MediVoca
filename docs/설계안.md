# 의학용어 전용 앱 설계안

Oct 31, 2026 · @KJ

## 한눈에 보기

의학용어를 **핵심 1,000 → 확장 500 → 2학년 이후 과목별 단어** 순서로, **하루 50장, 약 15분**씩 보며 외우는 별도 앱이다. 핵심 1,000개는 한 학기(약 16주)에 끝난다. 학습 방법의 뼈대는 "먼저 떠올리고 → 맞춰 보고 → 모르는 것은 자주, 아는 것은 드물게 다시 보기"다.

- **떠올린 뒤 평가**: 아는 정도를 고르기 전에 뜻을 먼저 떠올린다. "안다"를 고르면 정답과 맞춰 보고, 틀렸으면 단계가 내려간다. 느낌만으로 고르면 실제보다 안다고 착각하기 쉽다.

- **모르면 바로 설명**: "처음 봄"이나 "헷갈림"이면 뜻, 조각 분해, 어원, 암기법을 보여 주고, 같은 세션 안에서 한 번 더 떠올리게 한다.

- **반복 주기는 앱이 정함**: 단어마다 기억 상태를 계산해 잊어버리기 직전(기억률 90%)에 다시 보여 준다. 오픈소스 FSRS 방식이다.

- **조각 먼저, 단어는 가족으로**: 접두사·어근·접미사를 먼저 익히고, 같은 조각을 쓰는 단어를 묶어 배운다.

- **범위는 내가, 오늘 단어는 앱이**: 단계·장·★·교수님 목록으로 범위를 정하면, 앱이 그 안에서 오늘 볼 단어를 고른다.

- **하루 50장 = 복습 먼저, 남는 자리에 새 단어**: 처음엔 새 단어가 많고, 복습이 늘면 새 단어가 저절로 줄어 하루 시간이 일정하다.

- **앱 안의 공부 방법 안내**: 왜 이렇게 공부하는지 한 페이지로 보여 주고, 연구 결과와 앱이 정한 규칙을 구분해 적는다.

새 단어를 하루 50개씩 넣으면 1,000개를 3주 만에 끝내지만, 그동안 하루 약 1시간이 걸린다. 그래서 "하루 50장"을 기본으로 하고, 시험일을 넣으면 새 단어 수를 올리는 집중 모드를 둔다 (아래 계산).

## 근거: 효과가 확인된 방법만 쓴다

연구에서 효과가 가장 높은 것은 **스스로 떠올리기**(인출 연습)와 **간격을 두고 나눠 보기**다. 다시 읽기·밑줄·요약은 효과가 낮아, 앱에 "그냥 훑어보기" 화면은 두지 않는다.

| 방법 | 연구에서 알려진 것 | 앱에서 하는 방식 |
|---|---|---|
| 인출 연습과 간격 반복 | 10가지 학습법 중 연습 시험과 분산 학습만 "높음" 평가. 다시 읽기, 밑줄, 요약은 "낮음" ([Dunlosky 등, 2013](https://www.psychologicalscience.org/news/releases/which-study-strategies-make-the-grade.html)) | 카드는 항상 떠올리기부터 시작한다. 다음 복습일은 앱이 계산한다 |
| 기억률을 정해 두는 일정 (FSRS) | 목표 기억률만 정하면 되고, 높일수록 하루 복습이 늘어난다. 기존 Anki 방식보다 적은 복습으로 같은 기억률을 유지한다 ([Anki 설명서](https://docs.ankiweb.net/faqs/what-spaced-repetition-algorithm)) | 기본 90%, 시험 주간 95%, 여유 있을 때 85%로 고를 수 있다 |
| 사전 시험 | 답을 보기 전에 떠올리려다 실패해도, 그냥 공부한 것보다 더 잘 기억한다 ([Kornell 등, 2009](https://www.scientificamerican.com/article/the-pluses-of-getting-it-wrong/)) | 처음 보는 단어도 먼저 조각으로 뜻을 추측하게 한 뒤 설명을 보여 준다 |
| 연속 재학습 | 한 번 맞힐 때까지 떠올리고, 다른 날 다시 맞힌다. 항목마다 3번 맞히게 했더니 시험 점수가 한 등급 올랐고, 학생이 카드를 마음대로 빼면 효과가 사라졌다 ([Rawson·Dunlosky](https://www.retrievalpractice.org/archive/2018/successive-relearning)) | 모르는 단어는 같은 세션에서 맞힐 때까지 다시 나온다. 다른 날 3번 맞혀야 "익힘"이 되고, 카드를 빼는 것은 앱이 정한다 |
| 아는 정도 판단 | 공부 직후가 아니라 시간이 지난 뒤 단서만 보고 판단하면 거의 정확하다 ([Weaver·Kelemen, 1997](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.1997.tb00445.x/)) | 아는 정도는 영어 단어만 보고 뜻을 떠올린 뒤 고른다. 방금 본 단어는 몇 장 뒤에 다시 묻는다 |
| 조각(형태소) 분석 | 의학용어는 접두사·어근·접미사의 조합이라, 조각을 알면 처음 보는 단어도 뜻을 풀 수 있다 (설계 원칙) | 조각을 먼저 배우고, 같은 조각을 쓰는 단어를 이어서 보여 준다 |

억지 말 만들기 같은 암기법은 일반적인 효과가 "낮음"으로 평가됐다. 그래서 신체 부위나 뜻과 연결이 약한 조각, 자주 틀리는 단어에만 보조로 붙인다.

## 앱 안내 페이지: 의학용어 공부 방법

앱을 처음 열 때 한 번 보여 주고, 메뉴에서 언제든 다시 읽을 수 있는 한 페이지 안내다. 연구로 확인된 것과 이 앱이 정한 숫자를 구분해 적는다.

| 방법 | 이렇게 한다 | 근거 |
|---|---|---|
| 1\. 읽지 말고 떠올리기 | 단어를 보면 뜻을 먼저 떠올리고 나서 답을 본다. 다시 읽기보다 오래 남는다. | 연구 |
| 2\. 몰라도 먼저 추측하기 | 처음 보는 단어도 조각으로 뜻을 짐작해 본다. 틀려도 그냥 보는 것보다 잘 기억한다. | 연구 |
| 3\. 틀린 단어는 그날 다시 | 틀린 단어는 몇 장 뒤에 다시 떠올려, 그날 안에 한 번은 맞힌다. | 연구 |
| 4\. 잊을 때쯤 다시 | 1일 → 3일 → 8일 → 3주처럼 간격을 늘려 다시 본다. 다른 날 3번 맞히면 "익힘". | 간격 늘리기는 연구, 날짜와 3번은 앱 규칙 |
| 5\. "안다"는 확인하기 | 안다고 골랐으면 정답과 맞춰 본다. 느낌만으로는 실제보다 안다고 생각하기 쉽다. | 연구 |
| 6\. 몰아서 말고 매일 조금 | 시험 전에 몰아 보면 시험은 넘겨도 금방 잊는다. 매일 짧게 본다 (이 앱 기준 약 15분). | 연구, 15분은 앱 계산 |
| 7\. 장기별로 묶고, 헷갈리는 단어는 따로 | 같은 조각을 쓰는 단어는 묶어 배우되, dysphagia·dysphasia처럼 헷갈리는 짝은 같은 날 처음 배우지 않는다. | 묶기는 설계 원칙, 짝 떼기는 연구 (결과가 엇갈림) |
| 8\. 억지 연상은 보조로 | 말장난 암기법은 조각으로 풀리지 않는 단어에만 쓴다. | 연구 |

**하지 마세요**

- 형광펜 긋고 다시 읽기만 하기: 효과가 낮다.

- 한 번 맞혔다고 카드 빼기: 스스로 빼면 효과가 사라진다. 빼는 것은 앱에 맡긴다.

- 하루에 수백 개 몰아 넣기: 며칠 뒤 복습이 한꺼번에 몰려 와 포기하기 쉽다.

"연구"는 위 근거 표의 연구에서 온 것이고, "앱 규칙"과 "앱 계산"은 연구를 이 앱에 맞춰 정한 숫자다. 앱 안내 페이지에는 근거 칸을 작은 글씨로 넣고, 누르면 출처가 보인다.

## 콘텐츠: 핵심 → 확장 → 2학년 이후

졸업까지 볼 의학용어를 약 3,000개로 잡고 세 단계로 나눈다. 1학년 의학용어 수업 범위가 핵심과 확장 1,500개이고, 2학년부터는 과목마다 새 단어가 나온다.

| 단계 | 내용 | 개수 | 언제 |
|---|---|---|---|
| 1\. 핵심 | 1장 규칙 + 조각 250 + 단어 600 + 약어 150 (★★★·★★) | 1,000 | 1학년 의학용어 수업 (한 학기) |
| 2\. 확장 | 조각 50 + 단어 400 + 약어 50 (★) | 500 | 1학년 말, 방학 |
| 3\. 2학년 이후 | 계통별 질환·검사·시술·약물 용어. 과목별 단어 목록 (성인간호학, 아동간호학, 약리학 등) | 약 1,500 | 2~4학년, 과목 수업에 맞춰 |
| 합계 | | 약 3,000 | 졸업까지 |

- **다음 단계 열기**: 지금 단계의 80%가 "익힘" 이상이 되면 다음 단계를 권한다. 언제든 직접 열 수도 있다.

- **앞 단계도 계속 복습**: 단계가 바뀌어도 앞 단계 단어의 복습은 그대로 나온다. 익힌 뒤에는 간격이 길어 하루 5~10분이면 된다.

- **하루 50장**: 모든 단계의 복습을 먼저 채우고, 남는 자리를 지금 단계의 새 단어로 채운다.

- **RN 영어 설명**: 어느 단계에서든 설정에서 켜고 끈다.

참고로, 의학용어 사전에는 수만에서 십만 개가 넘게 실려 있다 (대한의사협회 의학용어집 6판 약 5만, Dorland's 약 12만). 학생용 교재는 수천 개 수준이다. 미국 교재 Chabner의 The Language of Medicine이 약 2,800개를 다룬다. 3,000개는 이 수준에 맞춘 추정이다.

핵심과 확장 1,500개는 조각 300, 단어 1,000, 약어 200으로 나눈다. ★★★과 ★★ 1,000개가 핵심, ★ 500개가 확장이다.

| 구분 | 전체 | ★★★ 자주 나옴 | ★★ 중요 | ★ 확장 | 지금 하랑노트에 있는 수 |
|---|---|---|---|---|---|
| 조각 (접두사·어근·접미사) | 300 | 150 | 100 | 50 | 292 |
| 단어 | 1,000 | 200 | 400 | 400 | 351 |
| 약어·단위 | 200 | 50 | 100 | 50 | 84 |
| 합계 | 1,500 | 400 | 600 | 500 | 727 |

**핵심을 고르는 기준** (하나 이상이면 ★★ 이상)

- 국시·학교 시험에 자주 나오는 단어

- 간호 기록, 인수인계, 투약에서 매일 쓰는 단어와 약어

- 단어를 많이 만드는 조각 (예: -itis, cardi/o, hyper-는 수십 개 단어에 들어간다)

- 병태생리학·건강사정에서 이어서 쓰이는 단어

공식 빈도 목록은 없다. ★은 위 기준으로 정한 추정이고, 교재 목차와 기출을 보고 고친다. 앱에서도 단어마다 ★을 바꿀 수 있다.

**배우는 순서**

1.  1장 규칙 (조각 구조, 결합모음, 읽는 순서, 복수형)

2.  두루 쓰이는 조각: 질환 접미사, 수술·검사 접미사, 위치·수·색 접두사

3.  계통별 장 (근골격 → 심혈관 → … → 피부): 그 장의 어근을 먼저, 다음 날부터 그 어근으로 만든 단어

4.  임상 약어는 해당 계통 장에 섞어 넣는다 (예: MI는 심혈관 장)

5.  핵심의 80%를 익히면 확장 500개, 2학년부터는 과목별 단어 목록

## 공부할 단어 고르기

범위는 내가 정하고, 그 안에서 오늘 볼 단어는 앱이 고른다. 내가 고르는 것은 "무엇을"이고, "언제, 몇 개씩"은 앱이 기억 상태를 보고 정한다.

**범위 (내가 고름)**

- **단계**: 핵심, 확장, 2학년 이후 과목 중에서 고른다.

- **장**: 수업 진도에 맞춰 "이번 주 범위"로 장을 고른다.

- **★**: 시험이 급하면 "★★★만"을 고른다.

- **종류**: 조각, 단어, 약어 중 일부만 볼 수 있다.

- **교수님 단어 목록**: 영어 단어를 붙여 넣으면 앱에 있는 단어는 바로 범위에 넣고, 없는 단어는 "내 단어"로 만든다. 이 목록은 내 폰에만 저장하고 GitHub에는 올리지 않는다.

- **아는 단어 거르기 (선택)**: 범위를 처음 정할 때 단어를 빠르게 넘기며 뜻을 떠올리고, 맞힌 단어는 새 단어에서 빼서 2주 뒤 복습으로 보낸다.

**오늘 단어 (앱이 고름)**

1.  **조각 먼저**: 단어에 들어가는 조각을 아직 안 배웠으면 조각부터 넣는다.

2.  **장기·어근별로 묶기**: 한 묶음 10개는 같은 조각을 쓰는 단어들이다.

3.  **헷갈리는 짝은 떼기**: dysphagia·dysphasia처럼 헷갈리는 짝은 같은 날 처음 배우지 않고, 한쪽이 "배우는 중"을 지난 뒤에 나머지를 넣는다.

4.  **순서**: 기본은 교재 목차 순서다. "★★★ 먼저"를 고르면 ★이 높은 것부터 넣는다.

5.  **개수**: 하루 50장에서 복습을 뺀 나머지다 (최소 5, 최대 30). 시험일 모드에서는 계산한 수를 따른다.

## 카드 한 장의 구성

앞면에는 영어 단어만 보이고, 설명은 아는 정도를 고른 뒤에 보인다. 모르면 전체 설명, 알면 뜻과 조각만 짧게 보여 준다.

| 항목 | 예: dyspnea | 언제 보이나 |
|---|---|---|
| 단어와 발음 | dyspnea · 디스프**니**아 (disp-NEE-uh), 발음 듣기 | 앞면 |
| 조각 힌트 | dys · pnea 로 끊어 보여 주고 뜻을 추측하게 함 | 앞면, 눌렀을 때만 |
| 뜻 | 호흡곤란 (같은 뜻의 다른 이름도 함께) | 항상 |
| 조각 분해 | dys- 어려움 + -pnea 호흡 | 항상 |
| 어원 | 그리스어 dys(나쁜, 어려운) + pnoia(숨) | 모를 때, 또는 펼치기 |
| 쉽게 푼 뜻 | 숨쉬기가 힘들고 숨이 찬 상태 | 모를 때 |
| 암기법 | 어려운 단어에만. 내가 만든 암기법을 가장 먼저 보여 줌 | 모를 때 |
| 같은 조각 단어 | apnea 무호흡, tachypnea 빈호흡, orthopnea 기좌호흡 | 모를 때 (이미 배운 단어만) |
| 헷갈리는 단어 | dysphagia 삼킴곤란 vs dysphasia 언어장애 | 헷갈릴 때, 또는 틀렸을 때 |
| 임상 문장 | Pt c/o dyspnea on exertion. (움직일 때 호흡곤란 호소) | 펼치기 |
| 영어 설명 (RN) | difficult or labored breathing · "I can't catch my breath." | 설정에서 켠 때 |
| 내 그림·메모 | 수업 자료 사진, 교수님 강조 | 내가 넣었을 때 |

**카드 방향**: 처음에는 영어를 보고 뜻을 떠올리는 카드만 나온다. 다른 날 3번 맞혀 "익힘"이 되면 한글을 보고 영어 철자를 쓰는 카드가 따로 생긴다. 알아보는 것보다 쓰는 것이 어렵기 때문에, 쉬운 방향을 먼저 익힌다. 철자 카드는 설정에서 끌 수 있다.

## 아는 정도 4단계와 반복 주기

뜻을 떠올린 뒤 4단계 중 하나를 고른다. "안다" 쪽(3·4단계)을 고르면 정답을 보고 맞았는지 한 번 더 누른다. 틀렸으면 1단계로 처리해서, 느낌만으로 간격이 늘어나는 일을 막는다.

| 단계 | 버튼 글자 | 오늘 하는 일 | 처음 다시 보는 날 |
|---|---|---|---|
| 1 | 모름 | 전체 설명 → 5장 뒤 다시 떠올리기 → 세션 끝에 한 번 더 | 다음 날 |
| 2 | 헷갈림 | 전체 설명 → 5장 뒤 다시 떠올리기 | 다음 날 |
| 3 | 알 것 같음 | 정답 확인 (맞음 / 틀림) | 약 4일 뒤 |
| 4 | 확실히 앎 | 정답 확인, 조각 뜻까지 | 약 2주 뒤 |

(그림은 원본 설계안 아티팩트에 있음)

카드 한 장이 지나가는 길 · 4단계, 확인 1번

모름·헷갈림은 그날 맞힐 때까지 다시 나오고, 안다고 골라도 틀리면 모름과 같은 길로 간다.

그 뒤 간격은 맞힐 때마다 대략 2~3배로 늘어난다. 처음에 "모름"이었던 단어를 계속 맞히면 **1일 → 3일 → 8일 → 19일 → 44일** 뒤에 다시 나온다 (FSRS 기본값으로 계산). 연속 재학습 연구의 일정(1·3·8·10·15일)과 비슷하다.

- **복습에서 틀리면**: 간격이 크게 줄고(보통 1~2일), 그날 안에 맞힐 때까지 다시 나온다.

- **단어마다 다르게**: 자주 틀리는 단어는 "어려움"이 올라가 간격이 천천히 늘고, 쉽게 맞히는 단어는 빨리 늘어난다.

- **끈질긴 단어**: 6번 넘게 틀리면 표시하고, 내 암기법을 만들거나 조각 카드부터 다시 보게 한다.

- **카드 상태**: 새 단어 → 배우는 중 → 익힘 (다른 날 3번 맞힘) → 오래 기억 (다음 복습까지 3주 이상). 진도는 "익힘" 이상만 센다.

- **선택지 4개인 이유**: 2개면 애매한 단어를 구분하지 못하고, 5개 이상이면 고르는 데 시간이 걸린다. FSRS의 다시/어려움/보통/쉬움과 하나씩 맞는다.

## 하루 학습 흐름

하루 50장은 **복습을 먼저 채우고 남는 자리를 새 단어로** 채운다. 새 단어는 하루 최소 5개, 최대 30개다. 같은 날 다시 나오는 카드는 50장에 세지 않는다.

1.  **시작 화면**: "오늘 복습 32 · 새 단어 18 · 약 15분"처럼 할 일과 시간을 보여 주고, 버튼 하나로 시작한다.

2.  **복습**: 오늘이 된 카드를 잊을 위험이 큰 것부터 보여 준다. 틀린 카드는 설명을 짧게 보고 5장 뒤에 다시 나온다.

3.  **새 단어 묶음**: 10개씩 묶는다. 한 묶음은 조각 1~2개와 그 조각으로 만든 단어들이다. 카드마다 추측 → 단계 선택 → 설명 순서로 지나간다.

4.  **묶음 확인**: 묶음이 끝나면 그 묶음에서 "모름·헷갈림"이었던 단어를 섞어서 다시 떠올리게 한다. 맞힐 때까지 다시 나온다.

5.  **마무리**: 오늘 처음 본 단어 중 "모름"이었던 것을 한 번 더 보고, 맞힌 수와 내일 할 일을 보여 준다.

- **중간에 나가도** 하던 곳이 저장되고, 다음에 열면 이어서 한다.

- **3분 모드**: 버스·쉬는 시간용으로 복습 10장만 본다.

- **빠진 날**: 밀린 복습은 며칠에 나눠 배정하고(하루 최대 100장), 그동안 새 단어는 쉬어 간다. 모두 한꺼번에 몰아서 포기하게 만들지 않기 위해서다.

- **주간 점검** (선택): 일주일에 틀린 단어만 모아 철자 쓰기·뜻 쓰기로 한 번 푼다.

## 하루 학습량 계산

새 단어를 많이 넣을수록 며칠 뒤 복습이 한꺼번에 몰려 온다. 하루 50장으로 고정하면 1,000개까지 16주가 걸리지만, 매일 15분 안팎으로 일정하다.

(그림은 원본 설계안 아티팩트에 있음)

FSRS-4.5 기본값으로 돌린 시뮬레이션 · 5회 평균, 17주

| 설정 | 1,000개 다 넣는 데 | 처음 30일 하루 카드 수 | 60일째 오래 기억한 단어 | 112일째(16주) 오래 기억한 단어 |
|---|---|---|---|---|
| 새 단어 50개 | 20일 | 138장 | 879 | 940 |
| 새 단어 30개 | 34일 | 107장 | 799 | 932 |
| 새 단어 20개 | 50일 | 73장 | 610 | 927 |
| 하루 50장 (기본) | 110일 | 52장 | 385 | 777 |

"오래 기억"은 다음 복습까지 3주 이상 남은 단어다. 하루 50장이 16주째에 낮은 것은 마지막 단어들을 막 넣었기 때문이다.

**추천**

- **기본은 하루 50장**: 한 학기 수업과 같은 속도고, 매일 비슷한 시간이라 꾸준히 하기 쉽다.

- **시험까지 8주 안팎**: 새 단어 20개. 7주 동안 하루 25~30분이 든다.

- **3주 안에 끝내야 할 때만**: 새 단어 50개. 3주 동안 하루 약 1시간이 든다.

- 앱에 시험일을 넣으면 남은 단어와 날짜로 새 단어 수를 계산해 제안한다 (아래 시험일 모드).

계산 조건: 처음 보는 단어 중 모름 50%, 헷갈림 25%, 알 것 같음 20%, 확실히 앎 5%. 복습 한 장에 8초, 모르는 새 단어는 설명과 다시 떠올리기까지 약 55초. 실제 시간은 사람마다 다르고, 앱은 내 기록으로 다시 계산한다.

## 시험일 모드

시험 날짜와 범위를 넣으면, 남은 날짜로 하루 새 단어 수를 계산해 "하루 50장" 대신 쓴다. 목표는 시험날 범위 단어를 90% 넘게 기억하는 것이다.

1.  **새 단어 수**: 남은 단어 ÷ 새 단어를 넣을 날. 새 단어는 시험 2주 전까지만 넣고, 그 뒤로는 복습만 한다. 시험이 4주 안쪽이면 복습만 하는 기간을 줄인다 (2주 남았으면 마지막 1주).

2.  **시간이 모자라면**: 하루 예상 시간이 40분을 넘으면 "★★★만 먼저"를 제안한다. 나머지는 시험 뒤에 넣는다.

3.  **시험 주간**: 목표 기억률을 95%로 올린다. 복습이 늘어나는 대신 시험날 기억이 올라간다.

4.  **마지막 3일**: 시험날 기억률이 90% 아래로 예상되는 단어만 모아 한 번씩 더 본다.

5.  **시험 뒤**: 목표 기억률을 85%로 낮춰 복습을 줄이고, 다음 단계나 다음 시험까지 유지한다.

| 남은 기간 | 범위 | 하루 새 단어 | 하루 평균 | 가장 많은 날 | 시험 3달 뒤 기억 |
|---|---|---|---|---|---|
| 16주 | 1,000 | 10 | 14분 | 22분 | 78% |
| 8주 | 1,000 | 23 | 25분 | 38분 | 72% |
| 4주 | 1,000 | 63 | 45분 | 78분 | 67% |
| 4주 | ★★★ 400 | 25 | 18분 | 31분 | 66% |
| 2주 | ★★★ 400 | 58 | 31분 | 59분 | 57% |
| 2주 | 1,000 | 143 | 78분 | 149분 | 57% |

여섯 경우 모두 시험날 기억은 약 95%로 같다. 다른 것은 하루 시간과 시험 뒤에 남는 양이다. 몰아서 할수록 하루가 길고 3달 뒤에 덜 남는다. 시험 후 오래 기억하려면 간격을 더 넓게 두는 것이 좋다는 연구(Cepeda 등, 2008)와 같은 방향이다.

계산 조건: 위 "하루 학습량 계산"과 같은 가정(FSRS-4.5 기본값)으로 4번 돌린 평균이다. 목표 기억률은 내내 90%로 두었고(3번 규칙은 빠짐), 복습만 하는 기간은 마지막 12일(2주일 때는 7일), 마지막 3일 규칙은 넣었다. "3달 뒤 기억"은 시험 뒤 복습을 안 했을 때의 예상치다.

## 어떻게 만드나

하랑노트와 별개의 앱으로 만든다. 매일 50장을 빨리 넘기려면 화면이 단순해야 하기 때문이다. 만드는 방식은 하랑노트와 같아서, 지금 코드와 의학용어 727개(영어 설명 포함)를 이어서 쓴다.

**기술**

- **앱 형태**: 설치하는 웹앱(PWA). 폰(안드로이드·아이폰)은 홈 화면에 추가하고, 컴퓨터는 크롬·엣지에서 설치 버튼을 눌러 앱처럼 쓴다. 같은 주소 하나로 두 기기를 모두 지원하고, 앱스토어 등록은 하지 않는다.

- **화면**: 폰은 세로 한 손 화면. 컴퓨터는 넓은 화면에 설명을 옆에 펼치고 키보드로 공부한다 (스페이스 = 정답 보기, 1~4 = 아는 정도, 철자는 바로 입력).

- **올리는 곳**: GitHub Pages. 하랑노트와 같다.

- **인터넷 없이**: 한 번 열면 단어 파일까지 기기에 저장되어, 지하철이나 실습 중에도 된다.

- **기록 저장**: 공부 기록은 기기 안(IndexedDB)에 저장한다. 카드 상태를 덮어쓰지 않고 "언제, 어떤 단어, 어떤 버튼"을 한 줄씩 쌓는다. 폰과 컴퓨터의 기록은 백업 파일을 카톡으로 옮겨 합친다 (가입 필요 없음). 두 기기에서 따로 공부해도 줄을 합친 뒤 다시 계산하면 되어 기록이 엉키지 않는다. 자동 동기화(Firebase)는 나중에 필요하면 붙인다.

- **백업 옮기기**: 폰에서 "백업 보내기"를 누르면 공유 창이 열려 카카오톡 나와의 채팅 등으로 바로 보낸다. 컴퓨터에서는 파일로 내려받고, 불러올 때는 창에 끌어다 놓는다. 불러오기는 덮어쓰지 않고 기록을 합치므로, 옛 파일을 불러와도 새 기록이 사라지지 않는다. 파일 이름에는 날짜와 기기를 붙인다 (예: 메디보카-백업-1031-폰).

- **복습 계산**: 공개된 FSRS 코드(ts-fsrs)를 쓴다.

- **발음**: 폰과 컴퓨터 브라우저에 들어 있는 읽기 기능(TTS). 음성 파일은 만들지 않는다.

- **교수님 자료와 내 사진**: 넣은 기기에만 저장하고 GitHub에는 올리지 않는다. 사진은 백업 파일에도 넣지 않아 파일을 작게 유지한다.

**기기별 설치와 백업 옮기기**

| 기기 | 설치 | 백업 보내기 | 백업 받기 |
|---|---|---|---|
| 안드로이드 폰 | 크롬으로 열고 "앱 설치" | 보내기 버튼 → 공유 창 → 카카오톡 | 카톡에서 파일 → 공유 → 이 앱 (바로 불러옴) |
| 아이폰 | 사파리로 열고 공유 → "홈 화면에 추가" | 보내기 버튼 → 공유 창 → 카카오톡 | 카톡에서 파일 → "파일에 저장" → 앱의 불러오기 |

카카오의 공식 "카카오톡 공유" 기능은 글·사진·링크로 만든 메시지만 보내고 파일은 못 보낸다. 그래서 기기의 공유 창을 쓴다. 카톡으로 받은 앱 주소를 누르면 카톡 안 브라우저로 열려 기록이 따로 저장되므로, 설치할 때는 사파리나 크롬으로 연다.

**데이터 파일**

단계와 장별로 파일을 나눠 필요한 것만 불러온다. 핵심은 장마다 terms-core-01.js, terms-core-02.js …, 확장은 terms-ext.js, 2학년 이후는 terms-y2-adult.js(성인간호학)처럼 과목별로 둔다. 항목 하나에는 아래 칸이 들어간다.

| 칸 | 예: dyspnea |
|---|---|
| id, 종류 | dyspnea, 단어 (조각 / 단어 / 약어) |
| 영어, 발음 표기 | dyspnea, 디스프니아 (disp-NEE-uh) |
| 한글 뜻 (여러 개) | 호흡곤란 |
| 조각 분해 | dys- 어려움 + -pnea 호흡 |
| 어원 | 그리스어 dys + pnoia |
| 쉽게 푼 뜻, 암기법 | 숨쉬기가 힘들고 숨이 찬 상태 |
| 헷갈리는 짝 | dysphasia |
| 임상 문장 | Pt c/o dyspnea on exertion. |
| 영어 정의, 쉬운 말, RN 팁 | difficult or labored breathing, "I can't catch my breath." |
| ★, 장, 단계, 과목 | ★★★, 호흡기, 핵심 |

**학습 엔진이 하는 일**

- 4단계 버튼을 FSRS 평가(다시, 어려움, 보통, 쉬움)로 바꾼다. "안다"를 골랐는데 틀렸으면 "다시"로 처리한다.

- 모름·헷갈림 카드는 5장 뒤에 다시 넣고, 맞힐 때까지 반복한다.

- 하루 50장을 배정한다. 모든 단계의 복습이 먼저, 남는 자리에 지금 단계의 새 단어(최소 5, 최대 30)다. 밀린 복습은 하루 최대 100장으로 나눈다.

- 새 단어는 "공부할 단어 고르기" 규칙(조각 먼저, 묶음, 헷갈리는 짝 떼기)대로 고른다.

- 상태를 계산한다. 다른 날 3번 맞히면 익힘, 다음 복습까지 3주 이상이면 오래 기억, 지금 단계가 80% 익힘이면 다음 단계를 권한다.

- 시험일 모드에서 하루 새 단어 수와 마지막 3일에 볼 약한 단어를 계산한다.

**하랑노트에서 가져오는 것**: 발음 듣기, 철자 쓰기 채점, 백업, 인터넷 없이 쓰기, 의학용어 727개와 영어 설명. 단어 파일은 두 앱이 같이 쓴다.

**만드는 순서**

1.  **1차, 매일 공부할 수 있게**: 727개를 새 형식으로 옮기고, 학습 엔진, 홈·학습·확인·설명·끝 화면, 카톡 백업 보내기와 합치기 불러오기를 만든다. 직접 1주 써 보며 카드 한 장 시간, 버튼 위치, 설명 길이를 고친다.

2.  **2차, 핵심 1,000개 완성**: 단어 약 250개와 약어 약 70개를 더하고, 모든 항목에 어원·발음 표기·임상 문장을 넣는다. ★을 다시 매기고, 범위 고르기와 시험일 모드를 붙인다.

3.  **3차, 다듬기**: 단어장, 통계, 설정, 공부 방법 페이지, 철자 카드, 확장 500개.

4.  **4차, 2학년 이후**: 과목 수업에 맞춰 과목별 단어 목록을 하나씩 더한다.

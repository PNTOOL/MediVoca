# 단어 데이터 형식

장마다 파일 하나(`terms-01.js` … `terms-16.js`). 한 줄이 항목 하나다.

| 칸 | 뜻 | 예 |
|---|---|---|
| `id` | 종류 + 영어. 조각 `p:`, 단어 `w:`, 약어 `a:` | `w:dyspnea` |
| `k` | 종류: `part` / `word` / `abbr` | `word` |
| `t` | 영어 (조각은 형태) | `dyspnea`, `cardi/o`, `-itis` |
| `ko` | 한글 뜻 목록. 같은 뜻 다른 말을 모두 넣는다 | `["호흡곤란"]` |
| `star` | 중요도 1~3 (★) | `3` |
| `stage` | 단계: `core` 핵심(★★·★★★), `ext` 확장(★) | `core` |
| `parts` | 단어의 조각 형태 (단어만, 없으면 빼도 됨) | `["dys-", "-pnea"]` |
| `full` | 약어의 영어 풀이 (약어만) | `per os` |
| `mean` | 쉽게 푼 뜻 | |
| `tip` | 암기 요령 `{k: 종류, s: 문장}`, `**굵게**` 가능 | |
| `memo` | 메모 | |
| `def`, `lay`, `rn` | RN 영어: 영어 정의, 쉬운 말 목록(환자 말은 “ ”), RN 팁 | |

- `pairs.js`: 헷갈리는 짝. `sa`와 `sb`의 항목은 같은 날 처음 배우지 않는다. `w`는 설명에 짝을 보여 줄 항목.
- `index.js`: 파일 목록. 새 파일을 만들면 여기에 더한다.
- 고친 뒤에는 `npm run check`로 빈 칸, 중복, 없는 조각 참조를 검사한다.
- 처음 727개는 `scripts/convert-harang.mjs`로 하랑노트에서 옮겼고, 나머지는 `scripts/add-terms.mjs`로 더했다(파일 맨 위에 형식 설명). 지금은 이 폴더가 원본이다.
